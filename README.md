# Meters Reader (EAC DSO Cyprus)

Утилита и веб-сервис на **Go** для мониторинга интервального энергопотребления с портала [EAC DSO](https://meterreading-dso.eac.com.cy/) (Кипр).

Поддерживает работу как в виде **локального консольного CLI / фонового демона**, так и в виде **веб-сервиса (готова к бесплатному деплою на Koyeb)**.

---

## 🔒 Приватность и архитектура веб-сервиса

* **Сервер не хранит учетные данные**: логин и пароль **не записываются** на диск, в базу данных или логи. Сервер выступает легковесным прокси — получает запрос от вашего браузера, кратковременно авторизуется на EAC, скачивает отчет, парсит его в памяти и отдает JSON.
* **«Запомнить меня» работает локально**: опция сохранения учетных данных использует только `localStorage` вашего браузера. При необходимости учетные данные удаляются кнопкой «Забыть мои данные».
* **In-Memory LRU-кеш**: чтобы не дергать портал EAC при каждом обновлении страницы и не создавать лишнюю нагрузку, результаты успешных отчетов кешируются в оперативной памяти сервера на 2 часа (по хешу `sha256(email:days)`).

## 🚀 Деплой на бесплатный хостинг Koyeb

### Способ через GitHub (Рекомендуемый):

1. **Создайте репозиторий на GitHub** и запушьте в него папку проекта:
   ```bash
   cd meters-reader
   git init
   git add .
   git commit -m "feat: EAC meter reader web service"
   git remote add origin https://github.com/<ваш-юзернейм>/meters-reader.git
   git branch -M main
   git push -u origin main
   ```

2. **Зайдите на [Koyeb.com](https://app.koyeb.com/)**:
   * Нажмите **Create App** $\to$ **GitHub**.
   * Выберите ваш репозиторий `meters-reader`.
   * **Builder**: выберите `Dockerfile` (Koyeb автоматически найдет готовый `Dockerfile` в репозитории).
   * **Instance Type**: выберите **Free Eco (Nano)** (512 МБ RAM, бесплатно).
   * Порт автоматически определяется как `8080`.
   * Никаких секретов или паролей в Koyeb вводить **не нужно**!
   * Нажмите **Deploy**.

Через 1-2 минуты сервис будет доступен по вашему публичному адресу:
`https://<app-name>-<org>.koyeb.app`

## 💻 Локальный запуск

### 1. Запуск встроенного веб-сервера (Web UI):
```bash
./meters-reader -server -port 8080
```
Откройте браузер по адресу: [http://localhost:8080](http://localhost:8080)

### 2. Запуск в консольном режиме (CLI):
```bash
# Однократная выгрузка по учетным данным из .env
./meters-reader

# Анализ существующего файла XLSX оффлайн
./meters-reader -file ./data/my_readings.xlsx

# Запуск демо-данных (без пароля)
./meters-reader -mock

# Фоновый демон с периодическим скачиванием
./meters-reader -loop
```

## 📊 Возможности веб-интерфейса и отчетов

* **Сводные метрики**:
  * Общий расход (кВт⋅ч).
  * Пиковый интервал с точной мощностью в кВт (`kW = kWh / 0.5h`).
  * Средний суточный расход.
  * Базовая постоянная нагрузка (покой).
* **Интерактивные графики Chart.js**:
  * График потребления по 30-минутным интервалам с подсказками.
  * Среднечасовой профиль (00:00 – 23:00) с подсветкой пиковых часов.
  * Столбчатая диаграмма расхода по дням.
* **Таблица топ-интервалов пиковой нагрузки** с расчетом эквивалентной мощности.
* **Индикатор кеша**: отображает, получены ли данные свежими с портала или отданы мгновенно из LRU-памяти.

## 📁 Структура проекта

```
meters-reader/
├── cmd/meters-reader/main.go  # Главная точка входа (CLI + запуск веб-сервера)
├── internal/
│   ├── cache/lru.go           # Потокобезопасный in-memory LRU кеш с TTL
│   ├── server/server.go       # HTTP сервер (API /api/fetch + раздача UI)
│   ├── client/eac.go          # Клиент к API портала EAC (авторизация, выгрузка)
│   ├── parser/xlsx.go         # Интеллектуальный парсер двухстраничного Excel EAC
│   ├── analyzer/analyzer.go   # Расчет мощности, пиков, часов и суточных сумм
│   └── visualizer/            # Консольная ASCII-визуализация
├── web/
│   ├── index.html             # Адаптивный веб-интерфейс (Chart.js)
│   └── web.go                 # Встраивание статики в бинарник (go:embed)
├── Dockerfile                 # Многоэтапная сборка минимального контейнера (~20 МБ)
├── .dockerignore
├── .env.example
├── go.mod
└── README.md
```
